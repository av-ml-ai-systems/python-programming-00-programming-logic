## 0. Introduction

Programming languages are only tools. Before learning Python—or any programming language—it is essential to develop the ability to think like a programmer.

This phase focuses on building the mental models that underlie software development. Rather than memorizing syntax, the learner will develop computational thinking, problem decomposition, algorithmic reasoning, and structured problem-solving skills.

Throughout the phase, problems will first be solved conceptually using natural language, flowcharts, pseudocode, and manual reasoning before being translated into Python in later phases.

This approach establishes a solid foundation that will support every subsequent phase of the roadmap, including Python programming, object-oriented design, algorithms, machine learning implementation, and technical interviews.

---

## 1. Phase Vision

Develop the mindset of a programmer by learning how to analyze problems, design logical solutions, and reason algorithmically before writing code.

The emphasis is on understanding the reasoning process behind programming rather than learning the syntax of a specific language.

---

## 2. Learning Objectives

By completing this phase, the learner should be able to:

- Explain what a computer program is.
- Describe how computers execute instructions.
- Apply computational thinking to solve problems.
- Decompose complex problems into manageable components.
- Design algorithms before writing code.
- Represent algorithms using flowcharts and pseudocode.
- Trace algorithms manually.
- Identify logical errors through systematic reasoning.
- Develop structured approaches to problem solving.
- Understand the importance of abstraction in software development.

---

## 4. Learning Outcomes

At the end of this phase, the learner will think about problems like a programmer rather than attempting to solve them immediately through code.

The learner will be capable of designing complete algorithmic solutions independently before implementing them in Python during the next phase.

---

## 5. Learning Philosophy

This phase follows a "logic before syntax" philosophy.

The objective is not to memorize programming language features but to develop transferable programming skills that apply across Python and other programming languages.

Every programming language changes.

Programming logic does not.

Consequently, every solution should first be designed conceptually before implementation.

Hands-on activities include:

## 12. Completion Criteria

This phase is successfully completed when the learner can:

- Analyze unfamiliar problems systematically.
- Design complete algorithms before coding.
- Trace algorithms manually.
- Identify logical errors.
- Explain the reasoning behind a solution.
- Demonstrate strong computational thinking.

---

## 13. Preparation for Phase 1

After completing this phase, the learner will possess the logical foundations necessary to begin learning Python syntax and programming constructs.

Rather than learning Python mechanically, the learner will understand how Python expresses algorithmic ideas developed during this phase.
